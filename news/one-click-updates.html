One-Click Updates from the Dashboard

Your users never need to touch a terminal again. Updates happen from a single button in the admin panel.

[ Screenshot: System Update Card ]

We've shipped a complete over-the-air update system. When a new version is available, the admin dashboard shows a notification with the changelog. One click triggers the full update pipeline — download, rebuild, restart.

How it works under the hood

  • The API checks our version server for new releases
  • Downloads the new release tarball from S3
  • Rebuilds Docker images locally (fast — pre-compiled binaries, no compilation on VPS)
  • Restarts all services with the new code
  • Frontend polls until the new version is confirmed running

What you see

In the admin dashboard, scroll to the System Update card. If an update is available, you'll see the new version number, release date, and a brief changelog. Click "Update" and wait about 60 seconds.

The button shows real-time progress as it polls for the new version. Once confirmed, it displays a success message with the new version number.

Automatic version checks

The system checks for updates every time you load the admin dashboard. No cron jobs, no manual checks. If you're on the latest version, you'll see a green "Up to date" badge.

Rollback safety

Before any update, the current binaries are backed up. If the new version fails to start, the previous binaries are preserved for manual recovery. In practice, every update we ship is tested on our own production instance before release.
